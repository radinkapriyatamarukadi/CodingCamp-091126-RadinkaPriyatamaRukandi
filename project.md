
# Expense & Budget Visualizer

## Project Overview
Expense & Budget Visualizer is a web-based application designed to help users track and manage their daily expenses.

## Technology Stack
- HTML
- CSS
- Vanilla JavaScript
- Chart.js
- Local Storage

## Main Features
- Add transactions
- Delete transactions
- Calculate total expenses
- Display spending distribution using a pie chart
- Save transaction data using Local Storage
- Custom categories
- Monthly expense summary
- Sort transactions by date and amount
- Dark and light mode

## Design Requirements
- Simple and modern interface
- Responsive layout
- Mobile-friendly design
- Easy to use
- Clear transaction information
